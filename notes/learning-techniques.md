# 🧠 Learning Techniques

Learning how to learn is one of the most valuable skills you can develop.

## Core Principles

### Spaced Repetition
Review material at increasing intervals to move it into long-term memory. Tools like flashcard apps use this method effectively.

### Active Recall
Instead of re-reading, test yourself. Closing the book and trying to recall information is far more effective than passive review.

### The Feynman Technique
1. Choose a concept.
2. Explain it as if teaching a child.
3. Identify gaps in your explanation.
4. Go back and fill those gaps.
5. Simplify your explanation further.

### Interleaving
Mix different subjects or problem types in a single study session rather than blocking topics. This builds stronger connections between ideas.
