# Test_Pages

A collection of interconnected markdown pages, similar to an [Obsidian](https://obsidian.md) vault, hosted on GitHub.

## Navigation

- [About](pages/about.md) — What this site is and how it works
- [Getting Started](pages/getting-started.md) — How to create and link pages
- [Topics](pages/topics.md) — Browse pages by topic

## About This Site

This project stores markdown files that form a linked website. Pages reference each other using standard markdown links — the same idea as Obsidian's `[[wiki-link]]` syntax, but portable to any markdown renderer including GitHub.

> **Tip:** On GitHub, clicking any `.md` link renders the target page immediately, so you can navigate the site just like a wiki.
