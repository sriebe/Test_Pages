## How to Add a Topic Section

1. Create a sub-folder inside `pages/` named after the topic, e.g. `pages/notes/`.
2. Add your markdown files there.
3. Come back to this page and add a new `##` section with a table row for each new page.

```markdown
## My Topic

| Page | Description |
|------|-------------|
| [My Page](my-topic/my-page.md) | Short description |
```
